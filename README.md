# Cuanti 2 — TG1

El proyecto editable se encuentra en `shiny_micromachismos/`.

Para comenzar:

1. Abre `shiny_micromachismos/shiny_micromachismos.Rproj` en RStudio.
2. Ejecuta `source("setup.R")` la primera vez.
3. Ejecuta `source("run_local.R")` para abrir la encuesta.

Consulta `shiny_micromachismos/README.md` para conocer el diseño, los archivos y el flujo de colaboración.

Aplicación publicada: https://taller-de-herramientas-cuantitativas2.shinyapps.io/tg1-dinamicas-grupales/
